# 无 Torch 运行期验收

这些工具只服务开发验收，不进入 Python 发行包。基线环境保留 Torch；候选环境不安装
Torch。每次报告必须携带模型图及全部 external-data 权重摘要、后端、依赖版本与硬件记录。

## 数值验收规则与当前限制

- dtype、shape、整数、索引和未改公式的确定性 NumPy 计算逐元素精确一致。
- ORT 回放保存的输入（含 token 历史、缓存和随机张量），相同模型／精度／后端／原生库
  的输出先要求逐元素精确一致。失败先保存首个差异，不能自动放宽阈值。回放通过还要求
  ORT 构建、参与计算的 NVIDIA/ORT 动态库摘要和模型身份一致；旧记录缺少外部权重摘要时
  只能标记为数值观察，不能事后补写摘要冒充历史证据。
- Whisper 不沿用统一 `1e-5` 门槛。下述初版区间实验已被独立审查降为观察数据，
  **不能作为等价验收通过证明**。它逐帧使用 float64 DFT 参考和估计预算：
  `u=2^-24`、`gamma(k)=k*u/(1-k*u)`。400 点实数 DFT 按直接复数乘加的保守上界
  `gamma(8*n+4)` 乘窗口化输入 L1 范数；窗口生成／乘法另计 `8u` 的逐样点误差。
  该界采用直接 DFT 的运算上界，尚未证明覆盖实际 FFT 算法，不能声称是本次 FFT 的严格界。
  平方模误差以 `2*|z|*e+e^2` 传播；mel 非负加权求和以 `gamma(2*n_freq)`
  及系数转换误差传播；经正值截断、log10、最大值减八、加四除四传播区间。
  初版 log10 的 4 ULP 假设及窗口误差假设也未取得库保证；区间自身未向外舍入。
  `whisper_rounding.py` 会保存结果后以失败退出；`whisper_stages.py` 逐阶段复现两条真实库
  路径并要求复现精确一致，但仍将最终数值验收记为未验证。
- ULP、绝对误差、有效非零区域的相对误差独立报告；ULP 在接近零处只作诊断。
- 空／静音 PCM 的原实现会产生异常或 NaN。修复归一化除零单独记录，不能算作浮点等价。
- 此门槛之外仍要记录真实 Smart Turn 概率和判定；没有模型／硬件／人工试听的项目为未验证。

## 运行记录与依赖

开发验证另需 `onnx==1.19.1`、`pytest`，合成资源统计还需 `psutil`；参考特征工具另需 Torch。
这些依赖不加入产品安装环境。`asr_probe.py` 和回放环境指纹在 Windows 用系统 API 读取已加载 DLL。
`TORCH_FREE_TRACE=<空目录>` 启用记录，`PYTHONPATH` 包含本工具目录时 `sitecustomize.py`
也会覆盖不重载主模块的子进程。默认保存全部调用；`TORCH_FREE_TRACE_SAMPLED=1` 只适合诊断，
不能冒充完整调用覆盖。每个 session 保存模型摘要、环境指纹和确定性设置。

S2-Pro 的旧默认 CUDA 图会因 TransposeOptimizer 改写归约轴而使用非确定性的浮点原子累加。
SDK codec 显式启用 `use_deterministic_compute=True`；旧环境可通过
`TORCH_FREE_DETERMINISTIC_CODEC=1` 采集同配置对照。此覆盖会写进元数据，原始失败样本继续保留，
同配置对拍不能替代旧默认行为到确定性行为的迁移验收。

## 保留原则

`.scratch/torch-free/` 下的基线、输入张量、试听 WAV 与报告必须保留到数值门槛通过
且用户完成试听。最终自由生成音频不做逐采样相等验收，也不由助手评价听感。
