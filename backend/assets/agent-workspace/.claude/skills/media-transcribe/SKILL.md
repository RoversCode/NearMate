# 音视频离线转写

当用户要求把本地音频/视频文件转成文字、生成字幕或做语音识别时使用本 Skill。底层复用 NearMate 内置的 Qwen ASR 引擎与 Silero VAD：长音频会先做 VAD 语音检测，在静音处切成不超过 30 秒的转写单元再逐段识别，所以任意时长的文件都可以处理，无需手动切分。

## 使用方法

1. 从任务材料清单中找到输入文件的绝对路径（常见音视频格式均可，mp4/m4a/mp3/wav 等）。
2. 调用本 Skill 的 `scripts/transcribe_media.py`，输出目录指向本次任务说明指定的交付目录。
3. 命令成功后从 stdout 最后一行的 JSON 里取得产出文件清单，确认文件真实存在，再在最终回复中列出绝对路径。

```powershell
python "${CLAUDE_SKILL_DIR}/scripts/transcribe_media.py" `
  --input "<音视频文件绝对路径>" `
  --output-dir "<任务交付目录>"
```

## 参数

| 参数 | 说明 |
| --- | --- |
| `--input` | 必填。输入音频或视频文件路径。 |
| `--output-dir` | 必填。转写结果输出目录。 |
| `--language` | 识别语言，默认 `Chinese`；英文内容传 `English`。 |
| `--formats` | 逗号分隔的输出格式：`srt,json,txt`，默认全部导出。后续要做内容分析时 JSON 最有用（含每段起止时间）。 |
| `--max-chunk-sec` | 单个转写单元的时长上限（秒），默认 30；一般无需调整。 |

## 行为说明与限制

- 产出时间戳是 VAD 语音段级别（通常一句话到几句话一段），不是逐词级别。
- 全程未检出语音时（常见于唱歌/纯音乐内容，VAD 对歌声判定保守），会自动回退为固定窗口整段转写，此时产出只有少量大段文本，时间戳粒度显著变粗。
- 长文件转写耗时与时长成正比；进度打印在 stderr，stdout 最后一行始终是结果 JSON。
- 首次运行需要加载本地模型，耗时几十秒属正常。
- 输入文件没有可解码音频、或本地模型资产缺失时，命令会非零退出并给出原因；如实汇报，不要伪造转写结果。
