# 视频内容摘要与深度解析

当用户没空逐帧看长视频、想知道"这个视频到底讲了什么"时使用本 Skill。产出不是泛泛的内容概括，而是带时间锚点的章节详解 + 术语逐个解释 + 逻辑脉络梳理。

## 前置条件

本 Skill 是工作流编排，实际下载与转写由另外两个受管 Skill 完成：

- B 站链接输入：需要 `bilibili-download` 已启用。
- 任意输入：需要 `media-transcribe` 已启用。

如果对应 Skill 未启用或其依赖未就绪，明确告知用户去技能库开启，不要绕过它们自行下载或转写。

## 工作流程

1. **获取音频**
   - 输入是 B 站链接：调用 `bilibili-download`，固定加 `--audio-only`（摘要不需要画面，速度快、体积小）。
   - 输入是本地音视频文件：直接使用该文件。
   - 如果用户明确要求结合画面（PPT 截图、演示操作），如实说明当前流程只覆盖音频内容，画面信息不会出现在摘要里。
2. **语音转写**：调用 `media-transcribe`（默认 `--language Chinese`，外语内容按实际语言调整），拿到带时间戳的 JSON 分段。
3. **分段精读**：转写很长时按时间段分批读入（每批约 10–15 分钟），每批维护滚动笔记：本章主题、出现的专有名词、论点与因果链、存疑点。读完全部再综合成文，不要只读开头就下结论。
4. **产出交付**：完整解析写成 markdown 文件放入任务交付目录，回复中给出精简版。

## 交付文档结构

```markdown
# <视频标题> 内容解析

- 来源 / 时长 / 转写语言
- 一句话概览

## 全文摘要
300–500 字，讲清核心议题、结论与价值。

## 分章节详述
按内容逻辑切分章节（不机械按时间等分），每章带起止时间锚点 [mm:ss]，
写清这一章具体讲了什么、举了什么例子、得出了什么结论。

## 关键名词与术语
逐个列出视频中出现的专业名词、术语、缩写，解释它在**本视频语境**中的
具体含义以及它在论述里的作用；禁止只给词典式通用释义。

## 逻辑脉络
还原视频的论证结构或操作流程：前提是什么、如何推导、结论如何成立；
教程类内容还原为可复现的步骤序列。

## 要点清单
关键结论与可执行要点的 bullet 列表，每条附时间锚点。
```

## 纪律

- 所有时间锚点必须来自转写 JSON 里的真实时间戳，禁止编造。
- 转写文本里听不清/识别错误的片段，在对应章节标注"（转写存疑）"，不要脑补。
- 纯画面信息（无语音的操作演示、板书）无法覆盖，在文档开头如实声明该局限。
