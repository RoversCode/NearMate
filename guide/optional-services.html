让当前角色完成后台工作

当你希望整理文件、处理材料或完成多步骤操作时，可以配置后台工作。它的模型服务和凭据与首次向导中的聊天服务分别保存。

  1. 打开控制台的设置 → AI 与服务 → 后台工作。
  2. 填写你所使用服务的 Base URL，以及 API Key 或 Auth Token。
  3. 选择后台工作主模型，确认服务支持该模型。
  4. 阅读权限说明，选择适合你的权限模式，再保存。

具体服务地址、模型名、凭据取得方式和价格由服务提供方决定。普通聊天已能连接，不代表后台工作服务也已配置。

先从一项范围清楚的小任务开始

“把这份会议记录整理成待办清单，保存为一个文本文件。”提交对应材料，并说明你希望得到什么文件。

当前角色会根据问题决定是否需要后台工作。任务运行期间，可以在聊天界面查看进展、权限请求、资料问题和结果；控制台的任务页也可以查看任务情况。

权限与补充资料由你决定

  • 请求权限：先阅读任务和需要执行的动作，再点击允许或拒绝。允许会覆盖当前任务后续的权限请求，不代表任务已经完成；新的任务需要重新判断权限。
  • 询问资料：在资料卡中提供答案或补充材料；明确不知道时，也可以如实说明。
  • 任务完成：查看聊天里的结果卡和交付文件，核对内容后再使用。

默认权限模式会对 Bash 等敏感操作请求确认。全权限模式需要你明确开启；选择前应理解它允许的操作范围。服务调用可能产生费用，可在后台工作用量页查看本地记录；真实账单以厂商为准。

普通后台工作一次只运行一项。当前任务还在执行或收尾时，新普通任务可能被拒绝，等它结束后再提出。执行中的目标说错时，清楚说明哪个目标需要纠正；文件或外部操作不保证能完整回滚。

交付文件默认放在 Windows“文档”目录下的 NearMate Workspace 中，聊天结果卡可以帮助定位。请保存需要长期保留的成果。

查询实时天气

如果你希望当前角色查询实时天气，需要另外配置和风天气服务。

  1. 按和风天气平台说明开通服务，取得项目的 API Host 与 API Key。
  2. 打开控制台的设置 → AI 与服务，找到天气凭据设置。
  3. 将 Host 与 Key 填入对应字段并保存。
  4. 回到聊天，说明城市和时间，例如“查一下北京今天的天气”。

Host 是平台分配的接口地址，Key 是调用凭据，二者不能互换。是否收费、可调用哪些接口和额度限制，以天气平台的账户说明为准。

没有配置时，天气工具会提示先配置；这不会阻止普通聊天和语音。配置后仍查询失败时，检查 Host、Key、服务权限及网络，再按页面给出的原因处理。

调整角色卡与虚拟形象

在控制台的角色卡页面调整当前角色的身份、语气和关系设定。角色卡决定“谁在陪你交流”；桌面的 Live2D 虚拟形象是她的视觉载体，可以通过人物模型入口单独调整。

改变语音模型或角色语音素材后，到 StreamVox 页面重新准备、试听并确认。仅下载另一款模型不会自动替换正在使用的声音；明确选择“准备并试听”才会进入切换流程。

创建或编辑角色时，把希望的语言风格和交流边界写清楚，比只堆砌性格标签更容易得到稳定体验。
