# NearMate 0.1.0 · 启动与首次配置修复版 4

这次更新让启动过程更连贯，也把首次配置整理成六个清楚的步骤。从安装完成到第一次聊天，每一步都有对应的说明与使用手册。

## 更新内容

- **启动进度更平滑。** 进度在当前准备阶段内持续推进；桌面窗口准备好后，先显示 100%，再交接到虚拟形象与首次配置页面，减少启动时进度长时间停住或突然跳完的感觉。
- **首次配置改为六步向导。** 按「产品授权 → DeepSeek → Qwen → 检查电脑 → 准备语音 → 试听并开始」完成准备。两家模型凭据共用配置草稿，在 Qwen 步骤统一验证并保存，前后切换步骤更方便。
- **完成后有明确的下一步。** 首次语音试听确认完成后，向导保留欢迎与开始使用的说明，点击「进入控制台」再打开日常管理页面。已经完成配置的用户仍可直接进入控制台。
- **加入使用手册入口。** 首次向导中的步骤说明可打开对应教程，控制台也提供常驻入口。[在线使用手册](https://roverscode.github.io/NearMate/guide/) 覆盖安装、首次配置、聊天与语音、选配功能和问题排查。

启动窗口的 100% 表示桌面入口准备完成。首次使用仍需按向导取得产品授权、配置模型 API 并准备和确认语音，完成后才能开始正常交流。

## 修复

- 启动时页面迟迟未能加载或虚拟形象未能显示首帧，会结束本次启动并显示失败反馈，避免一直停在启动进度中。
- 启动交接完成前，快捷键、托盘或再次启动程序不会提前召出虚拟形象；退出过程中也不会意外重新显示窗口。
- 首次试听确认触发运行时准备、或准备失败后重试时，向导仍会保留完成交接页，避免刚完成配置就突然跳走。
- 欢迎页不再提前加载尚未进入的角色卡页面，可选天气配置保留在设置页，减少首次准备时的干扰。

## 下载与安装

面向 Windows x64，提供两个版本：

| 版本 | 适用电脑 | 必须下载 |
| --- | --- | --- |
| CUDA · NVIDIA 版 | 配备兼容 NVIDIA 显卡的电脑 | `NearMate-cuda-setup.exe` 和本次发行的全部 CUDA `.bin` 分卷 |
| Universal · 通用版 | AMD / Intel 等其他设备；提供 DirectML、Vulkan 与 CPU 路径，支持情况通过首次向导确认 | `NearMate-universal-setup.exe` 和本次发行的全部 Universal `.bin` 分卷 |

请完整退出 NearMate，将所选版本的安装程序与**全部 `.bin` 分卷**放在同一文件夹，保持原文件名，再运行 `.exe`。不要混用两个版本或不同 Release 的分卷。附件 `SHA256SUMS.txt` 提供全部安装文件的校验值。

## 升级说明

安装器识别现有安装并确认升级信息完整后，可以在原目录升级。升级只替换程序文件；角色配置、产品授权和已下载的模型缓存保存在安装目录之外。

较早版本的安装目录可能缺少升级所需的信息，安装器会保留旧目录并提示无法接管。遇到该提示，请保留用户数据，先卸载旧程序或选择空目录安装，再按应用内提示继续配置。

首次使用需要申请试用或填写 NearMate Key，配置自备模型 API，并完成设备检查、语音模型准备和试听。试用领取受服务开放时间、每日名额与设备资格限制，以应用内结果为准；试用不包含模型 API 额度，第三方模型服务单独计费。
