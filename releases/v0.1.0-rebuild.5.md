# NearMate 0.1.0 · 后台工作配置修复版 5

本次修复控制台后台工作配置自动带入普通 LLM 模型的问题。应用版本保持 0.1.0，本次发行标识为 `v0.1.0-rebuild.5`。

## 修复

- **后台工作主模型独立填写。** 控制台不再根据 Foreground 等普通 LLM 职责生成后台工作模型候选或自动补入主模型。请填写后台工作服务支持的准确模型名。
- **空配置保持空白。** 尚未保存主模型时，打开后台工作设置不会自动填入 `deepseek-flash` 等聊天模型；保存配置前必须明确填写主模型。
- **已保存值继续保留。** 打开设置时保留已有的后台工作主模型。若曾保存自动带入的聊天模型，请按后台工作服务的要求核对并手工修改。
- **高级别名不会选定主模型。** Opus、Sonnet、Haiku 的模型别名映射继续由用户配置，填写这些映射不会自动选中或替代后台工作主模型。

## 配置说明

在控制台的「设置 → AI 与服务 → 后台工作」中，分别填写 Claude Code 兼容服务的 Base URL、API Key 或 Auth Token，以及明确的主模型。后台工作的端点、凭据和模型配置独立保存。
