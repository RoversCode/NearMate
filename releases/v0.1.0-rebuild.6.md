# NearMate 0.1.0 · 授权购买入口更新版 6

本次为产品授权页面增加直接购买入口。应用版本保持 0.1.0，本次发行标识为 `v0.1.0-rebuild.6`。

## 更新

- **直接购买授权 Key。** 激活码输入框下方新增“购买授权 Key”链接，点击后在浏览器新标签页打开购买页面。
- **两个授权入口均可购买。** 首次授权页面和“管理产品授权”窗口共用该入口，方便首次购买或试用结束后继续使用。
- **默认角色卡同步更新。** 安装包内置角色卡包含本次性格、关系边界与表达示例的调整。

[购买授权 Key](https://catfk.com/item/6wwzyw) · [首次授权手册](https://roverscode.github.io/NearMate/guide/first-run.html#license)

## 下载与安装

选择适合这台电脑的 CUDA 或 Universal 版本，下载对应的 `.exe` 和全部 `.bin` 分卷。将同一发行、同一版本的所有文件放在同一文件夹，保留原文件名，再运行 `.exe`；请勿与旧发行分卷混用。

升级替换程序文件，既有角色配置、产品授权和下载的模型缓存保存在安装目录之外。

NearMate 产品授权不包含模型 API 额度。DeepSeek、Qwen 及后台工作接入的模型服务由对应厂商单独计费。
