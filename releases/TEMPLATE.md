## 下载与安装

面向 Windows x64，提供 CUDA 与 Universal 两个版本。CUDA 用于配备兼容 NVIDIA 显卡的设备；Universal 提供 DirectML、Vulkan 与 CPU 路径，实际支持情况以应用内检查为准。

下载所选版本的 `.exe` 与全部 `.bin` 分卷，放在同一文件夹并保持文件名，然后运行 `.exe`。不要混用两种版本的分卷。用附件 `SHA256SUMS.txt` 核对文件摘要。
