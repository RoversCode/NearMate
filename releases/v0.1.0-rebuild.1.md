# NearMate 0.1.0 安装修复版

此版本处理安装后的图标、媒体工具依赖和模型管理问题。程序版本与云端授权发行仍为 **0.1.0**；`rebuild.1` 标识此次重新构建，已有授权可继续使用。

## 更新内容

- 桌面和开始菜单快捷方式使用 NearMate 品牌图标。
- CUDA、Universal 均自带 FFmpeg 8.1.2 和 ffprobe，媒体 Skill 无需用户另装 FFmpeg。
- 语音模型库逐个显示已下载、未下载、下载未完成及当前使用状态。下载其他模型保留现有语音；下载后可选择准备、试听并确认使用。
- 准备另一语音模型时留在管理页面，确认后更新当前模型和音色。
- Live2D 模型切换成功后保存所选模型，保留自我介绍、补充说明和快捷键等已有设置。
- Live2D 切换的失败原因显示在模型列表上方；请求未被接纳或人物设置无法确认时会提示并允许重试，模型列表可滚动。

## 下载与安装

- **Universal**：适用于 AMD、Intel 显卡和 CPU；可选择 DirectML、Vulkan 或 CPU。
- **CUDA**：适用于支持相应 CUDA 运行环境的 NVIDIA 显卡。
- 下载所选版本的 **EXE 和全部 BIN 分卷**，放在同一目录，再运行 EXE。请勿混用原版与修复版的分卷。
- 退出 NearMate 后安装到原目录。安装器保留安装目录外的用户配置、角色卡和已下载模型；这些位置中已有的完整模型可继续使用。
- 本页的 `SHA256SUMS.txt` 可用于核对所有安装文件。安装程序尚未使用 Windows Authenticode 签名。

NearMate 继续接入云端授权中心，支持激活码与试用领取；能否领取由服务端当前开放策略决定。模型服务 API 凭据仍由用户配置。
