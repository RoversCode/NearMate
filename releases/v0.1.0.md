# NearMate v0.1.0

NearMate 是常驻 Windows 桌面的 AI 工作搭子环境。角色由你定义，围绕手头的屏幕和材料交流，并在配置与授权后推进后台工作。

## 这一版可以做什么

- 用角色卡设置当前角色的身份与语气，搭配 Live2D 虚拟形象。
- 通过文字与语音交流，在首次向导中下载语音模型并完成试听。
- 使用当前屏幕、选中文字、截图和文件作为本轮材料上下文。
- 配置后台工作服务后，让当前角色调用工具处理多步骤任务，并查看进度、权限请求和结果。
- 在应用内申请 24 小时试用，无需先填写 NearMate Key。领取结果受服务开放时间、每日额度与设备资格限制，以应用内实时状态为准。

## 下载哪个版本

| 版本 | 选择建议 |
| --- | --- |
| CUDA | 配备兼容 NVIDIA 显卡的 Windows x64 电脑 |
| Universal | AMD / Intel 等其他设备；提供 DirectML、Vulkan 与 CPU 路径，支持情况请通过首次向导确认 |

**请下载所选版本的 `.exe` 与全部 `.bin` 文件。** 把同一版本的所有分卷放在同一文件夹，保持原文件名，再运行 `.exe`。请勿混用两个版本的分卷。附件 `SHA256SUMS.txt` 提供所有安装文件的 SHA256。

## 首次使用

1. 安装并打开 NearMate，在应用内申请试用或填写 NearMate Key。
2. 配置自备的模型 API，费用由模型厂商单独收取。NearMate 试用不包含 API 额度。
3. 完成设备检查、语音模型下载和试听，再开始桌面交流。
4. 如需后台工作，在控制台单独配置相应服务、主模型、凭据与权限。

## 当前边界

- 当前提供 Windows x64 版本，实际性能取决于硬件与选择的模型。
- 首次准备需要联网。试用的每次新会话也需要联网；设备资格与额度由服务裁决。
- 部分能力使用外部模型或服务，相关对话及选用的屏幕、材料内容可能发送至已配置的服务。
- 近期对话与任务上下文属于运行期记忆，后台进程退出后不会继续保留；角色卡与设置单独保存。
