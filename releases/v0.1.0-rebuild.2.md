# NearMate 0.1.0 · 体验修复版 2

这次更新改善了激活后的等待体验，并修复 Live2D 人物卡片的点击与切换问题。

## 更新内容

- **激活通过后立即进入下一页。** 输入 NearMate Key 后只等待授权验证；必要的模型和语音初始化会在下一页单独显示进度。
- **初始化进度持续显示。** 窗口显示当前准备内容，完成后自动继续；失败时保留提示并提供重试入口。准备期间不能关闭进度窗口，也不能跳过初始化。
- **Live2D 人物卡片可以正常点击。** 选择并确认切换后保存所选虚拟形象，显示实际加载结果；设置读取或保存失败会给出提示。

安装包继续自带 FFmpeg 和 NearMate 品牌图标。已下载的语音模型、角色配置与本机授权保存在用户数据目录中。

## 下载和安装

选择适合电脑的一个版本，将对应的安装程序和**全部 `.bin` 分卷**下载到同一文件夹，再运行安装程序。

| 版本 | 适用电脑 | 必须下载 |
| --- | --- | --- |
| CUDA | 使用受支持的 NVIDIA 显卡 | `NearMate-cuda-setup.exe` 和全部 3 个 CUDA `.bin` 分卷 |
| Universal | AMD、Intel 显卡或需要通用版本 | `NearMate-universal-setup.exe` 和全部 2 个 Universal `.bin` 分卷 |

请完整退出 NearMate 后安装。不要混用不同 Release 的安装程序或分卷；可以用 `SHA256SUMS.txt` 核对文件。
