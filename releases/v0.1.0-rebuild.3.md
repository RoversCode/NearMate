# NearMate 0.1.0 · 状态反馈修复版 3

这次更新让聊天窗口和桌面虚拟形象清楚表达当前角色的状态，也让快捷键切换「需要唤醒 / 无需再唤醒」的结果更容易察觉。

## 更新内容

- **聊天状态更明确。** 状态标题和状态球共同区分「等待唤醒」「无需再唤醒」「正在听」「思考中」「正在回复」「执行任务中」和「等待你处理」；需要授权或补充信息时，进一步显示「等你授权」或「等你补充」。
- **虚拟形象有常驻状态图案。** 人物头侧的小光环通过图标、颜色和轻量动画表达同一状态，没有可见文字标签；独立的唤醒模式点提示是否需要再次唤醒。图案跟随人物，聊天窗口展开时也会保留。
- **快捷键切换有两秒确认反馈。** 收到后台确认后，状态图案短暂强调切换结果；连续切换可以重新触发反馈。启用系统减少动态效果时，仍保留颜色和图标提示。

唤醒模式只说明是否需要再次唤醒。当前角色在聆听、回复或执行任务时，界面仍会单独表达唤醒要求；麦克风和语音连接是否可用，以应用内实际状态为准。

## 修复

- 快速切换或状态消息先后顺序变化时，切换确认不再遗漏，较早的消息也不会让当前状态回退。
- 自动唤醒或普通语音状态更新不再提前结束两秒强调反馈。
- 运行时重新连接或重启后，新的切换确认能够正常显示，不会受旧运行时的反馈记录影响。
- 连续使用快捷键时，光环反馈会重新播放；重复收到同一次确认不会重复强调。
- 安装包补齐本地依赖所需的 Microsoft Visual C++ 运行库，修复干净 Windows 环境因缺少 `MSVCP140.dll` 或 `MSVCP140_1.dll` 导致依赖加载失败的问题。

## 下载与安装

面向 Windows x64，提供两个版本：

| 版本 | 适用电脑 | 必须下载 |
| --- | --- | --- |
| CUDA · NVIDIA 版 | 配备兼容 NVIDIA 显卡的电脑 | `NearMate-cuda-setup.exe` 和本次发行的全部 CUDA `.bin` 分卷 |
| Universal · 通用版 | AMD / Intel 等其他设备；提供 DirectML、Vulkan 与 CPU 路径，支持情况通过首次向导确认 | `NearMate-universal-setup.exe` 和本次发行的全部 Universal `.bin` 分卷 |

请完整退出 NearMate，将所选版本的安装程序与**全部 `.bin` 分卷**放在同一文件夹，保持原文件名，再运行 `.exe`。不要混用两个版本或不同 Release 的分卷。附件 `SHA256SUMS.txt` 提供全部安装文件的校验值。

## 升级说明

安装器识别现有安装并确认升级信息完整后，可以在原目录升级。升级只替换程序文件；角色配置、产品授权和已下载的模型缓存保存在安装目录之外。

较早版本的安装目录可能缺少升级所需的信息，安装器会保留旧目录并提示无法接管。遇到该提示，请保留用户数据，先卸载旧程序或选择空目录安装，再按应用内提示继续配置。

首次使用需要申请试用或填写 NearMate Key，配置自备模型 API，并完成设备检查、语音模型准备和试听。试用领取受服务开放时间、每日名额与设备资格限制，以应用内结果为准；试用不包含模型 API 额度，第三方模型服务单独计费。
