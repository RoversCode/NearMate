使用手册

开始之前首次初始化聊天与语音选配功能遇到问题

设置完成以后

从一句话开始

先确认文字聊天正常，再检查声音设备。聊天窗口负责日常交流，控制台负责设置。

  1. 发送第一条消息
  2. 开始语音交流
  3. 聊当前屏幕
  4. 把材料交给角色
  5. 常用快捷键

发送第一条消息

  1. 把鼠标移到桌面角色上，点击旁边的聊天气泡图标。
  2. 在聊天输入区输入一句话，例如“你好，介绍一下你能怎么陪我工作”。
  3. 点击发送，等待当前角色回答。

回答会出现在聊天窗口中。聊天展开时，主要对话内容在这里呈现；控制台不承担日常聊天。

可以接着问：“我正在写一封邮件，帮我把语气改得自然一点。”先给出要改的文字，再说明希望的语气，比只说“帮我写”更容易得到适合的回答。

输入尚在准备或排队时，还没有正式进入对话。出现准备失败提示时，先按提示重试或修改；语音输入可能暂时暂停尚未发送的文字，请查看待发状态后决定是否恢复。

开始语音交流

完成首次语音试听后，先打开控制台的设置 → 声音与语音检查麦克风，再在 Windows 声音设置中检查播放设备。

  1. 在音频设备设置中确认输入设备。使用系统默认设备，或者手动选中需要的麦克风。
  2. 执行麦克风测试，按提示录制短音频。检查音量结果并回放，确认能听到自己的声音。
  3. 更改麦克风后，按页面操作保存并等待应用结果。在 Windows 中确认输出设备、系统音量和应用音量正常。
  4. 说出当前角色的唤醒词，或使用追问快捷键开启跟进，再对角色说话。

默认角色火花的唤醒词为“你好火花”和“火花同学”。换角色或改过唤醒词后，以控制台角色卡 → 唤醒入口中的当前配置为准。

被唤醒后，当前角色可能先给一个短回应，然后进入正式交流。跟进开启时，你可以在一次回应后继续补充，不必每句话都重新唤醒。

默认追问快捷键是 Ctrl + Alt + Space。它会切换免唤醒跟进，并立即停止当前讲话；如果你修改过快捷键，以设置页显示并成功登记的组合为准。跟进状态不确定时，先观察界面状态，再开始说话。

控制台的“扬声器参考”用于回声消除，不是选择播放输出的开关。播放设备在 Windows 声音设置中调整。第一次测试建议用一句短问题，例如“现在可以听见我吗？”，确认正常后再继续。

如果角色没有回应、试听没声音或麦克风测试失败，请查看声音问题排查。

聊你当前正在看的内容

把需要讨论的窗口放在屏幕上，再告诉当前角色你想了解哪一部分。例如：“看一下当前页面，这段说明是什么意思？”NearMate 会围绕本次交流的电脑现场理解问题。

如果页面文字很小、窗口被遮挡或你要精确讨论一张图，更稳妥的做法是把对应截图或图片拖入聊天输入区，再一起发送。说明“重点看图右侧的表格”，可以帮助角色定位。

屏幕内容可能按功能需要发送到你配置的模型服务。发起交流前，先隐藏不需要讨论的密码、账户信息和私密窗口。

把材料交给当前角色

  1. 将图片、文件或支持的材料拖入聊天输入区，检查待提交材料列表。
  2. 在正文里说明目标，例如“请把这份文档整理成三个要点”。
  3. 把材料和这次问题一起提交。

加入输入区的材料，要随这次交流提交以后才成为本轮材料。发送前可以移除不需要的项目；移除待提交项目不会删除你的原文件。

选中网页或软件中的文字、图片和片段后，可以按收集选中内容快捷键加入待提交材料。默认是 Ctrl + Alt + C；收集以后，回到聊天检查内容，再补充你希望怎么处理。

短粘贴直接作为正文，较长的粘贴可能转成材料。独立链接也可以放进正文，并说明你希望查询或讨论什么。

近期材料入口可以重新使用当前运行期间仍可找到的本地文件。文件移动、删除或退出后台进程后，不保证还能继续使用。需要长期保留的信息，请保存原文件和任务成果。

常用快捷键

  • 追问：Ctrl + Alt + Space，切换跟进，并停止当前讲话。
  • 桌宠召回：Ctrl + Alt + P，召回并置顶虚拟形象，再按一次收起。
  • 收集选中内容：Ctrl + Alt + C，将选中的内容加入待提交材料。

这些是默认值。控制台设置 → 常用可以修改或关闭快捷键。保存后查看登记结果；如果组合被其它软件占用，请换一个组合，不要只根据“已保存”判断系统快捷键已经生效。
