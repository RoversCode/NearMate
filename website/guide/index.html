下载适合这台电脑的版本

当前支持 Windows x64。配备兼容 NVIDIA 显卡的电脑可选择 CUDA 版；AMD、Intel 等设备可查看 Universal 通用版。安装后还会检查这台电脑的实际运行能力。

  1. 打开官网下载区，选中一个版本。
  2. 逐个下载这个版本的 .exe 安装程序和全部 .bin 分卷。
  3. 将它们放在同一文件夹，保留文件名，然后双击 .exe 安装。
  4. 从桌面或开始菜单打开 NearMate，进入首次初始化。

不同版本或不同发行的分卷不能混用。不要只下载 .exe；缺少任意分卷都无法完成安装。软件自带必要运行组件，不需要另外安装 Python、Torch 或 CUDA Toolkit。

开始前准备什么

  • 可用网络。首次配置要访问模型服务，并下载选定的语音模型。
  • 两家模型服务的凭据。DeepSeek 用于日常对话；Qwen（阿里云百炼）用于检索和深入理解任务。可以在向导对应步骤按指引取得。
  • 足够的磁盘空间。语音模型较大，向导会显示所选模型的下载大小，也可以选择其它磁盘保存。
  • 声音设备。打字不需要麦克风；使用语音时，需要可用的麦克风和扬声器或耳机。

免费软件与模型服务费用

NearMate 免费开源，软件与内置语音没有产品付费门槛或使用期限。

DeepSeek、Qwen 和选配后台工作的模型 API 由用户自行准备，费用由对应厂商收取。请在厂商平台检查服务开通状态、余额和调用限制。第三方模型与素材继续适用各自许可。

桌面角色、聊天窗口、控制台各做什么

  • 桌面角色是平时最方便的入口。鼠标移到角色附近，可以打开聊天、人物模型和控制台。
  • 聊天窗口用来打字、提交材料、查看回答、处理任务提问和查看结果。
  • 控制台用来完成首次初始化，以及管理角色卡、声音、模型服务和偏好设置。

角色卡定义当前角色的身份、语气和声音；虚拟形象是桌面上的视觉载体。二者可以分别调整。

使用时记住这两件事

对话以及选用的屏幕和材料内容，会按功能需要发送给已配置的模型服务。模型厂商的数据政策和费用需要由你自己确认。

近期对话与任务上下文保留在当前运行期间；退出后台进程后不继续保留。设置与角色卡单独保存。需要长期保存的成果，请及时保存交付文件。
