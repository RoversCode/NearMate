# NearMate v0.2.0 · 免费开源版

NearMate 现已采用 Apache-2.0 开源，软件与内置语音免费使用。本版取消产品激活、试用时限、设备名额、到期检查和购买入口。

## 更新内容

- 首次打开直接进入五步配置：DeepSeek、Qwen、检查电脑、准备语音、试听并开始。
- 内置 StreamVox 升级为公开开源版 2.0.0。
- 保留运行时准备、失败重试和任务操作权限，模型服务仍由用户自行配置。
- 公开应用源码、测试、开发说明和构建流程，同步更新官网、手册与演示。

## 下载与升级

选择 CUDA 或 Universal，下载所选 profile 的安装程序和全部 BIN 分卷，保留原文件名放在同一文件夹，再运行 EXE。两个 profile 与不同发行的分卷不能混用。

新版本可在安装器确认完整旧发行清单后原地升级，保留安装目录外的角色、模型与用户配置。模型 API 及后台工作服务由对应厂商单独计费。第三方模型和素材适用各自许可。
