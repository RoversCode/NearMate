# NearMate v0.3.0 · Q 版大肥鱼与语音交互

本版新增「大肥鱼（Q版）」桌面虚拟形象，支持随语音开口、随当前角色状态变化的表情，以及轻点反馈和逗趣动作。NearMate 是实时语音交互的智能桌面助手：可以用语音交代任务，让它操作电脑与网页、处理文件，并在执行中询问进展、纠正错误目标或取消任务。

## 本次更新

- 新增大肥鱼（Q版）的模型切换、桌面构图与交互区域适配。新安装默认使用该形象，已有用户的形象选择保留。
- 新增敲锤、自拍、吹泡泡等动作，并与真实语音口型配合；说话时避开遮挡嘴部的动作。
- 源码运行可从固定镜像自动准备实时输入模型，并显示准备进度。
- 修复资源下载响应中断时未继续尝试其他来源的问题，改善退出期间被取消任务的资源清理。
- 重写 README 的 Voice Agent 能力总览与语音任务示例，说明电脑操作、网页操作、文件处理及任务控制的使用方式。

## 下载与安装

本版提供 Windows x64 的两个安装版本，功能相同：

| 版本 | 适用设备 |
| --- | --- |
| CUDA | 配备兼容 NVIDIA 显卡的电脑 |
| Universal | AMD、Intel 等设备，可使用 DirectML、Vulkan 或 CPU；由首次向导确认支持情况 |

1. 下载所选版本的 `NearMate-<profile>-setup.exe` 和该版本的全部 `.bin` 分卷。
2. 将文件放在同一目录，保留原文件名，用 `SHA256SUMS.txt` 核对完整性。
3. 运行安装程序，按首次向导连接模型 API、检查设备、准备语音并完成试听。

不要混用不同版本或不同 profile 的分卷。建议使用默认安装目录或较短路径。安装程序尚未使用 Windows 代码签名。

使用 Agent 执行任务还需在控制台配置后台工作服务；电脑和网页操作需启用「电脑与浏览器操作」技能。插话会打断当前回复，停止后台任务需明确要求取消；取消不会自动撤销已经发生的文件修改或外部操作。
